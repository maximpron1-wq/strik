# Стрік

Трекер звичок, план на день, цілі на тиждень і місяць, нагороди за XP.
Статичний сайт (GitHub Pages) + Supabase (таблиця `strik_state`, вхід email + пароль, той самий акаунт, що й у My Orders).

## Мої гроші (`/finance`)

Облік доходів, витрат і кредитів з дашбордом (iOS-стиль, рідке скло). Окремий PWA у папці `finance/`.
Supabase: таблиця `finance_docs` (по документу на місяць + `meta` з кредитами й налаштуваннями), той самий вхід email + пароль.
